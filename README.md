## Environment Setup

Clone the repository:

```bash
git clone https://github.com/Ramjv2127/-Langchain_Langgraph_Learning.git
cd -Langchain_Langgraph_Learning
```

Create virtual environment:

```bash
uv venv
```

Activate environment:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
uv sync
```

Create a `.env` file:

```env
OPENAI_API_KEY=your_openai_api_key
